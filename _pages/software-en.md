This page provides calculation and analysis tools developed through our research. Each release will include its validation scope, version history, and usage notes.

## Concrete Thermal Conductivity Estimator

A tool for estimating temperature-dependent thermal conductivity of concrete and deriving piecewise approximation equations.

**Key features**
- Thermal conductivity calculation by temperature
- Piecewise equations and coefficients
- Result tables and plots

> The web application and user guide will be linked after release.

## HRR Curve Analysis Tool

A tool for analyzing heat release rate (HRR) data obtained from experiments or literature and extracting key curve parameters.

**Key features**
- HRR data import
- Growth, peak, and decay analysis
- Curve modeling and result output

> The application link and version history will be added after release.

## Notice

Results depend on input data and modeling assumptions. Users should review the applicable range and limitations before using the tools for research or engineering purposes.
