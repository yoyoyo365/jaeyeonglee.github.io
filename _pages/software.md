## Concrete Thermal Conductivity Estimator

콘크리트의 온도 변화에 따른 열전도율을 추산하고 구간별 근사식을 산출하는 도구입니다.  
A tool for estimating the temperature-dependent thermal conductivity of concrete and deriving piecewise approximation equations.

**주요 기능 | Main Features**

- 온도별 열전도율 계산  
  Calculation of thermal conductivity at different temperatures

- 구간별 근사식 및 계수 산출  
  Derivation of piecewise approximation equations and coefficients

- 계산 결과표 및 그래프 제공  
  Generation of calculation tables and graphs

> 프로그램 실행 링크와 사용자 매뉴얼은 업로드 후 연결합니다.  
> Program access and the user manual will be linked after upload.

## HRR Curve Analysis Tool

실험 또는 문헌에서 확보한 열방출률(HRR) 자료를 이용하여 곡선을 분석하고 주요 파라미터를 산출하는 도구입니다.  
A tool for analyzing heat release rate (HRR) data obtained from experiments or literature and extracting key curve parameters.

**주요 기능 | Main Features**

- HRR 데이터 불러오기  
  Import of HRR data

- 상승·최성기·감쇠구간 분석  
  Analysis of growth, peak/fully developed, and decay phases

- 곡선 모델링 및 주요 결과 출력  
  Curve modeling and output of key parameters

> 프로그램 실행 링크와 버전 이력은 업로드 후 연결합니다.  
> Program access and version history will be linked after upload.
